⏰ Digital Clock with Matrix Style Background
A Digital Clock that not only displays the current time and date but also features a unique Matrix-style animation effect in the background.
The clock uses a cascading green text effect, reminiscent of the famous Matrix movie, combined with real-time updates for time and date.

🚀 Features
🕰️ Displays the current time in a digital format (hours, minutes, seconds)
📅 Shows the current date (day, month, year)
🎨 Matrix-style animated background with cascading green characters
🌙 Clean and minimalist interface

🎮 How to Use
Open the HTML file in your browser.
The current time and date will automatically be displayed and updated in real-time.
In the background, you'll see a Matrix-style animation running behind the clock.

🛠️ Technologies Used
HTML – Basic structure of the page, including time/date display
CSS – Styling for both the clock and background effect
JavaScript – Manages the clock functionality and creates the Matrix animation
Matrix Animation: Random characters cascading in green across the screen, fading and resetting after a random amount of time

🔧 Instructions
The background animation is built using HTML5 Canvas to create the "Matrix" effect.
The setInterval method is used to continuously update both the clock and the background every second.
